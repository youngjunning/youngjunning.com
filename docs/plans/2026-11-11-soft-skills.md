# 软实力评测与成长模块

- 状态：待线上验收
- 最近核对：2026-11-11
- 目标：让读者先理解常见软实力方向，再基于本站已审核资料查看 AI 辅助评测、依据与可尝试的成长建议。

## 已定范围

- 能力地图是通用参考，不代表俊宁具备这些能力；参考 OECD 与 WEF 的公开框架。
- 个人评测由模型从本站共享记录和文章候选中提取，逐字引用本站来源。本人说某项能力重要或提出职业目标，不作为能力证明。
- 评测是带日期的内容快照。维护命令输出草案，人工核对后更新 `content/soft-skills.json`；访问和构建均不实时调用模型。
- 评测与建议只使用本站可公开的来源；书面材料不外推口头表达、团队协作或影响力成效。

## 进展与证据

- `/soft-skills` 已有原版与纸上状态图两种视图，导航与窄屏入口已接入。
- `npm run content:check`、`npm test`、`npm run typecheck` 和 `npm run build` 已通过；本地页面的两套主题均读到能力地图、评测、建议与来源。
- 线上部署和实际访客阅读尚未核验。

## 下一步

推送后核对部署结果和 `/soft-skills` 线上页面；取得真实读者对可读性的反馈，以及口头表达或协作过程的直接证据时，再重新评测并审阅结论。
