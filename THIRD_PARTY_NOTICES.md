# React Bits

`components/reactbits/spotlight-card.tsx` and `gradient-text.tsx` are simplified adaptations of React Bits SpotlightCard and GradientText, retrieved 2026-11-01:

- https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/Components/SpotlightCard/SpotlightCard.tsx
- https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/TextAnimations/GradientText/GradientText.tsx

Adaptations: semantic Next.js card links, opt-in style, local pointer events instead of global animation loops, CSS linear text animation, site palette, keyboard focus and reduced-motion support. No additional runtime dependencies.
