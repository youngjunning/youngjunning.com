# 软实力模块

`/soft-skills` 分开呈现两类内容：

- **能力地图**：依据 OECD 与 WEF 的公开框架整理常见方向，只帮助读者理解“软实力有哪些”，不代表对俊宁或紫升的评测。
- **个人评测**：`content/soft-skills.json` 是截至 `assessedAt` 的 AI 辅助评测快照。每个结论保留可回查的本站资料引用、证据强度、成长建议与下一次需要的证据。

当前目标为 `public`。候选资料只取本站已分享的个人记录与文章；不跨站读取、复制原始材料或把计划当成已具备的能力。本人说某项能力重要、希望成长，也不能单独作为能力证明。书面材料不能证明口头表达、倾听或团队影响力。

## 更新流程

1. 内容变化后，在本站运行 `node --env-file=.env.local scripts/assess-soft-skills.mjs --draft`，查看模型草案和实际发送的候选资料。正常命令 `npm run soft-skills:assess` 只向标准输出给出通过逐字引用检查的报告，不自动写入内容文件。
2. 人工核对每条引用、能力归类、证据强度和受众。删除把工程技能当软实力、用职业目标推断现有能力、或由单方材料推断他人评价的结论。成长建议只能写成可尝试的行动。
3. 保留同一能力维度的稳定 ID，用补丁更新 `content/soft-skills.json`，填写实际评测日期、模型和资料指纹。旧评测如需留作历史，再按本站内容协议归档。
4. 运行 `npm run content:check`、`npm test`、`npm run typecheck` 和构建；核对两套主题的页面、引用链接与窄屏。提交、推送、部署和线上可读状态分别验证。

报告不会在访问页面或构建时调用模型；新资料进入站点后，需要重新生成并审阅。
